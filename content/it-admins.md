# OpenLake for IT Administrators
If you are reading this, you are probably an IT administrator at your organization. **Here's a quick overview of what we need from you.**

Please whitelist or unblock the following domains:

- `*.github.com`, `github.dev` - GitHub, an industry standard for code hosting and collaboration, owned by Microsoft.
- `raw.githubusercontent.com` - serves files from GitHub repositories, used for workshop content.
- `openlake.iitbhilai.ac.in` - OpenLake's primary domain, hosts the club website and community content.
- `openlake.github.io` - hosts project documentation and showcases.
- `figma.com` - collaborative design tool used in design workshops.
- `i.ibb.co` - image hosting used for sharing screenshots and assets.
- `youtube.com`, `youtube-nocookie.com` - video tutorials and recorded talks.

Feel free to read on for more details and potential alternatives.

## GitHub

Besides the typical HTTP(S) ports, ports 22 and 9418 need to be open for SSH and Git respectively.

## Inspect Element / Developer Tools

Browser developer tools (e.g. Inspect Element) are required for web development projects, so that sites can be debugged and styled.
